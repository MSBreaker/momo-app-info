나의 대화,
이어지는 기억.

MOMO는 PC와 Android에서 캐릭터와 글·음성으로 대화하는 개인용 AI 애플리케이션입니다.

이 사이트는 MOMO의 기능과 데이터 처리 방식을 설명하는 공개 안내 페이지입니다. 앱을 내려받거나 개인 대화와 기억을 열람하는 사이트가 아닙니다. 현재 일반 공개 배포 서비스로 운영하지 않습니다.

기기 사이에 이어지는 기억

선택적으로 Google 계정을 연결하면 장기 기억과 최근 사건·약속에 관한 대화 메모를 자신의 Google Drive 내 MOMO 전용 숨김 저장공간에 동기화합니다. PC와 Android에서 같은 Google 계정을 사용합니다. 한 기기가 꺼져 있을 때의 변경은 그 기기가 다시 연결되면 반영됩니다.

이 기능에서 동기화하는 ‘최근 사건·약속’은 대화용 메모입니다. 기기의 캘린더 일정 데이터와는 별개입니다. 서로 다르게 수정한 기억은 사용자가 내용을 선택하도록 보류할 수 있습니다.

Google 연결의 범위

MOMO가 요청하는 Drive 권한은 drive.appdata, 즉 앱 전용 데이터 접근 권한입니다. 일반 Drive 문서 전체를 읽거나 공유하는 기능은 제공하지 않습니다. 대화 기록 전체, 화면 이미지, 음성 파일, API 키와 기기 설정은 기억 동기화 파일에 포함하지 않습니다.

사용자가 선택하는 대화 기능

AI 답변, 음성 인식·합성, 웹 검색과 이미지 질문은 사용자가 연결한 외부 서비스와 기기 기능을 이용합니다. 해당 기능을 사용하면 필요한 입력이 해당 서비스에 전달될 수 있습니다. 자세한 범위와 저장·삭제 방법은 개인정보처리방침에서 확인할 수 있습니다.
