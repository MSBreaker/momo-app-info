MOMO 소개이용 안내

개인정보처리방침

적용일: 2026년 11월 1일 · 운영: MSBreaker

이 안내는 개인용 MOMO 애플리케이션의 데이터 처리와 이 공개 안내 사이트에 적용됩니다. MOMO는 광고·정보 판매를 목적으로 운영하지 않습니다.

1. 기기에 저장하는 정보

MOMO는 사용자의 대화 기록, 직접 저장하거나 대화에서 추출한 장기 기억, 최근 사건·약속 메모, 사용 설정을 기기에 저장합니다. 외부 AI·음성·검색 서비스의 API 키는 해당 기능 설정에 사용합니다. PC와 Android의 저장 방식은 서로 다르며, PC의 설정 파일과 백업은 사용자가 접근을 관리해야 합니다.

2. Google 계정과 기억 동기화

사용자가 Google 연결을 승인하면 https://www.googleapis.com/auth/drive.appdata 권한으로 자신의 Google Drive에 있는 MOMO 전용 숨김 저장공간에 접근합니다. 연결 계정을 구분하기 위해 계정 이메일 및 Drive 사용자 식별 정보에서 계산한 값을 사용할 수 있습니다.

동기화 대상은 장기 기억의 항목명·내용·출처·수정 시각, 최근 사건의 제목·원문 인용·날짜·상태·출처·보관 기한, 그리고 변경 순서·항목 ID·삭제 표시 등의 동기화 정보입니다. 연결 검사에는 내용 없는 검증용 식별 코드가 사용됩니다. 일반 Drive 파일 전체 접근, 다른 사용자와의 기억 공유는 요청하지 않습니다.

대화 기록 전체, 화면 이미지, 녹음 파일, API 키, 기기 설정, 기기 캘린더의 일정 데이터는 기억 동기화 대상이 아닙니다. 다만 사용자가 대화에서 말해 기억으로 저장한 정보는 메모 내용에 포함될 수 있습니다. 저장을 원치 않는 민감한 정보는 입력하지 않거나 기억 메뉴에서 확인·삭제하세요.

PC의 Google 인증 정보는 현재 Windows 사용자에 연결된 암호화 저장소를 사용하며, Android 인증 처리는 Google Play 서비스에 위임합니다. 동기화 내용은 Google 계정의 앱 데이터로 저장되며 별도의 종단간 암호화 기능을 제공하지 않습니다.

‘최근 대화도 공유’를 켠 경우, 기기별로 최근 최대 10회 왕복의 대화 텍스트와 전달용 식별자·갱신 시각을 별도 파일에 저장합니다. 긴 대화는 용량 제한에 따라 더 적은 회차가 포함될 수 있습니다. 다른 기기의 대화는 사용자가 선택할 때 현재 대화 맥락으로 가져옵니다. 이미지·녹음·실행 대기 중인 도구 작업은 포함하지 않지만, 대화에서 언급한 개인정보나 일정 설명은 텍스트에 포함될 수 있습니다.

3. AI·음성·검색·캘린더 기능

AI 대화에는 사용자가 설정한 AI 제공자(예: Google Gemini)에 질문, 필요한 대화 맥락과 관련 기억이 전달됩니다. 음성 인식은 Android의 음성 인식 제공자에, 음성 합성은 설정한 합성 제공자(예: Fish Audio)에 필요한 음성 또는 텍스트를 전달할 수 있습니다. 웹 검색을 켜면 검색어가 설정한 검색 제공자(예: Tavily)에 전달됩니다.

이미지를 첨부하거나 현재 화면 전송을 허용한 경우 요청에 필요한 이미지가 AI 제공자에 전달됩니다. 캘린더 권한을 허용하면 선택한 기기 캘린더를 조회하고, 일정 쓰기 작업은 별도 내용 확인 후 적용합니다. 이 정보는 대화 요청을 처리하는 데 사용될 수 있으며 Drive 기억 동기화와는 별개의 기능입니다. 각 외부 서비스의 보관·사용 조건은 해당 제공자의 정책과 사용자의 계정 설정을 따릅니다.

4. 보관·삭제·연결 해제

장기 기억은 사용자가 삭제할 때까지 저장합니다. 최근 사건은 앱의 보관 기한에 따라 대화 참고 대상에서 제외됩니다. 기간이 지났다고 모든 파일에서 즉시 삭제되는 것은 아닙니다. 동기화의 재등장을 막기 위한 삭제 표시와 변경 이력, 기기 내 백업에는 관련 정보가 남을 수 있습니다.

기억 메뉴에서 항목을 삭제하면 연결된 다른 기기가 다음에 동기화할 때 삭제가 전달됩니다. 자동 동기화를 끄면 새 동기화 확인을 중단하지만 이미 진행 중인 요청이나 기존 저장 정보까지 삭제하지는 않습니다. Google 계정의 연결된 앱 관리에서 MOMO 접근 권한을 취소할 수 있습니다. 권한 취소만으로 기기나 Drive의 기존 데이터가 자동 삭제되는 것은 아닙니다.

전체 삭제가 필요하면 Google Drive의 앱 관리에서 MOMO의 숨김 앱 데이터를 삭제하고, 각 기기의 앱 데이터와 별도로 만든 백업도 정리해야 합니다. 한 기기나 클라우드의 데이터만 지운 상태에서 다른 기기의 동기화를 다시 켜기 전에 복구·재전송 여부를 확인하세요.

최근 대화 공유를 끄면 새 전송은 중단하지만 기존 클라우드 파일과 기기 내 사본은 남습니다. 새 대화 텍스트를 공유하면 같은 기기의 클라우드 대화 파일을 갱신합니다. 태블릿에서 이어받기 직전 대화는 복구본 하나로 보관되며, 다음 이어받기 또는 복구 때 교체됩니다. PC에서 선택해 가져온 대화는 별도의 로컬 대화 기록으로 남습니다. 클라우드 파일 교체·삭제만으로 다른 기기가 이미 가져온 기록까지 지워지지는 않습니다.

5. 공유와 사용 제한

MOMO의 기억 동기화는 사용자가 승인한 Google 계정과 사용자의 기기 사이에서 동작합니다. 운영자가 별도의 중앙 기억 서버를 운영하거나 광고 업체에 기억을 판매·공유하는 기능은 없습니다. Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy의 Limited Use 요구사항을 따릅니다.

6. 이 안내 사이트

이 사이트에는 로그인, 기억 업로드, 광고, 별도 분석 스크립트나 문의 입력 폼이 없습니다. 정적 호스팅 제공자인 GitHub는 사이트 제공 및 보안을 위해 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.

7. 문의와 변경

문의는 MOMO 안내 저장소에서 할 수 있습니다. 공개 문의에 개인 기억·대화·API 키·인증 정보를 첨부하지 마세요. 기능이나 처리 방식이 바뀌면 이 페이지의 적용일과 내용을 갱신합니다.
